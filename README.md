## Project Description
This project extends my Lab 1 personal portfolio by adding an interactive feedback form using JavaScript. The website is built with HTML, CSS and Vanilla JavaScript.

## Implemented Features
- Interactive feedback form with Full Name, Email, Topic of Interest, Comments and optional Website fields.
- Form validation with error messages and red/green input borders.
- Live character counter for Comments with a minimum requirement of 15 characters.
- Success message displaying the user's name after valid submission.
- Automatic removal of the success message after 4 seconds.
- Clear button to reset the form and validation states.
- Accessible form labels, error messages and keyboard focus styling.
- Responsive layout for desktop and mobile screens.
- Navigation between the portfolio homepage and feedback page.

## How to Run
1. Download or clone the repository.
2. Open 'index.html' in a web browser.
3. Click 'Feedback' in the navigation menu to open the feedback form.
4. Fill in the form and click Submit Button to test the validation.
5. Click 'Home' to return to the portfolio homepage.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Notes
The feedback form runs entirely in the browser. It does not send emails or store submitted feedback on a server.

## CSS Organization
The portfolio uses a shared `style.css` file for both the homepage and the feedback page. The feedback form's validation states, focus styles, transitions, and responsive rules are included in this stylesheet to maintain a consistent design across the website.
